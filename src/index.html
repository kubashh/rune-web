Installation guide

1. Download the executable for your operating system.

2. Make the downloaded file executable.

3. Move the executable to a directory in your PATH.

Linux

Run those commands:

sudo cp ./path_to_exe /usr/local/bin/rune

sudo chmod +x /usr/local/bin/rune

rune --help

MacOS

Run those commands:

sudo cp ./path_to_exe /usr/local/bin/rune

sudo chmod +x /usr/local/bin/rune

rune --help

Windows

Run those commands:

mkdir "%LOCALAPPDATA%\rune"

>copy /Y "C:\path\to\rune_exe" "%LOCALAPPDATA%\rune\rune.exe"

then add this to User PATH:
Win+R → sysdm.cpl → Enter Environment Variables → under User variables select Path → Edit… New → add: %LOCALAPPDATA%\rune OK → OK

rune --help

Deinstallation guide

Just remove the executable from your system.

Linux/MacOS

Run those commands:

sudo rm -f /usr/local/bin/rune

Linux/MacOS

Run those commands:

sudo rm -f /usr/local/bin/rune

Windows

Run those commands:

del "%LOCALAPPDATA%\rune\rune.exe"
